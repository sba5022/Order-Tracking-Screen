# Order Tracking Screen

A modern and responsive **Order Tracking Screen** built with Next.js and Tailwind CSS. This project provides users with a simple way to view order information, track delivery progress, and understand the current status of their orders.

## Features

* 📦 View order details
* 🚚 Track order delivery progress
* 📍 Display courier and tracking information
* 🕒 Show order status and delivery timeline
* ⚠️ Handle delayed orders
* 🔒 Handle unavailable tracking information
* ✅ Show delivered order status
* 📩 Report an issue with an order
* 💬 Contact support through a support modal
* 📱 Fully responsive design
* ✨ Smooth animations and transitions
* 🎨 Clean and modern user interface
* 🌙 Mobile-friendly layout

---

## Order Status

The application supports different order statuses:

### Shipped

The order has been shipped and is currently on its way.

### Processing

The order has been confirmed and is being prepared for shipment.

### Delivered

The order has successfully been delivered.

### Delayed

The order is experiencing a delivery delay.

## Responsive Design

The interface is designed to work across different screen sizes, including:

* 📱 Mobile devices
* 📱 Tablets
* 💻 Laptops
* 🖥️ Desktop screens

Special attention was given to smaller mobile screen widths around **360px–430px**.
